# Inspector website

The static marketing website for https://inspector.dev, built with Astro, TypeScript and SCSS.

## About Inspector

Inspector monitors your PHP application in production. Its MCP server gives your coding agent the errors, slow queries and stack traces it needs to fix the problem in your code.

- **Monitoring tool:** see every request, job and error in production.
- **MCP server:** connect your coding agent to production data.
- **AI Bug Fix:** get a proposed fix for production errors.
